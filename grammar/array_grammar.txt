Array Declaration Language (Current)

Terminals
---------
TYPE        -> int | float | char
IDENTIFIER  -> C-like identifier
INTEGER     -> integer literal
FLOAT       -> floating-point literal
CHARACTER   -> character literal

Grammar
-------
program             -> statement* EOF
statement           -> arrayDeclaration | assignment
arrayDeclaration    -> TYPE IDENTIFIER '[' expression? ']'
                       ('=' initializer)? ';'
initializer         -> '{' (expression (',' expression)* ','?)? '}'
assignment          -> lvalue '=' expression ';'
lvalue              -> IDENTIFIER ('[' expression ']')?
expression          -> addition
addition            -> multiplication (('+'|'-') multiplication)*
multiplication      -> unary (('*'|'/'|'%') unary)*
unary               -> ('+'|'-') unary | primary
primary             -> INTEGER | FLOAT | CHARACTER
                     | IDENTIFIER ('[' expression ']')?
                     | '(' expression ')'

Parser constraint: if size is omitted (`TYPE name[]`), an initializer is required.

Semantic checks
---------------
1. Reject non-positive array sizes.
2. Reject duplicate declarations.
3. Reject undeclared identifiers/arrays.
4. Reject non-integer indexes.
5. Reject out-of-range literal indexes.
6. Reject initializer lists larger than declared size.
7. Enforce assignment compatibility:
   - allowed: exact match, int->float, char->float, char->int, int->char
   - rejected: float->int, float->char
