
# Array Declaration Compiler – Grammar Documentation

## 1. Introduction

The Array Declaration Compiler is a compiler front end that recognizes array declarations, initialization, indexing, and element assignments.

The grammar defines the valid syntax of these statements using a Context-Free Grammar (CFG).

## 2. Grammar Objectives

- Recognize array declarations with a data type, identifier, and size.
- Support optional array initialization.
- Recognize array element access and assignments.
- Support arithmetic expressions.
- Provide a grammar for the parser.

## 3. Sample Input

```c
int arr[5];
int marks[3] = {10, 20, 30};
arr[2] = 50;
x = arr[2];
```

## 4. Sample Derivation

Consider the input:

```c
int arr[5];
```

Using the grammar:

```text
Program
=> StatementList
=> Statement
=> Declaration ;
=> Type ID [ INT_LITERAL ] InitializerOpt ;
=> int arr [ 5 ] ;
```

The input is generated by the grammar and is syntactically valid.

## 5. Array Initialization

Consider:

```c
int marks[3] = {10, 20, 30};
```

The declaration contains a data type, array name, size, assignment operator, and initializer list.

The initializer list contains comma-separated expressions enclosed in braces.

## 6. Array Element Assignment

Consider:

```c
arr[2] = 50;
```

The left-hand side represents an array element. The right-hand side represents the assigned expression.

The compiler must check whether the array is declared and whether the index is valid.

## 7. Grammar Design and Transformations

The expression grammar separates expressions and terms:

```text
Expression -> Term ExpressionTail
ExpressionTail -> + Term ExpressionTail
                 | - Term ExpressionTail
                 | epsilon

Term -> Factor TermTail
TermTail -> * Factor TermTail
           | / Factor TermTail
           | epsilon
```

This structure gives multiplication and division higher precedence than addition and subtraction.

The repeated expression-tail and term-tail rules avoid left recursion in these expression productions.

The grammar uses repetition rules for statement lists and initializer lists.

No additional left factoring is required for the expression rules shown above.

## 8. Semantic Checks

The grammar checks syntax. Additional semantic analysis is required to check:

1. Whether an array has been declared.
2. Whether an index has an integer type.
3. Whether an index is within the array bounds.
4. Whether an assigned value is compatible with the array element type.
5. Whether the initializer follows the supported type and size rules.

## 9. Limitations

The grammar supports a simplified C-like array syntax.

Multidimensional arrays, pointers, functions, and advanced C language features are outside the current scope unless added by the project team.

## 10. Conclusion

The CFG provides the syntactic foundation for the Array Declaration Compiler. It supports array declarations, initialization, indexing, assignments, and arithmetic expressions. The parser and semantic analyzer use this foundation to validate input programs.
